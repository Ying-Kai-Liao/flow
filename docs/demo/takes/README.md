# flow demo videos

Every take made for the flow demo, kept here so none get lost. The README uses `t8-hybrid`
(as `../flow-demo.gif`, linking to `../flow-demo.mp4`). Made 2026-10-13/14 from a real screen recording of the
Flow pane; files are web-size encodes.
